# Missingness strata and S7 analyses

These scripts recompute the revision's supplementary analyses from the saved
outer-fold predictions. They do not train models. Install the analysis
dependencies into your Python environment:

```sh
python -m pip install numpy pandas pyarrow openpyxl
```

First obtain the public FORCE 2020 data
([Zenodo record](https://doi.org/10.5281/zenodo.4351156)) and run the revision
dataset, training and reporting workflow documented with this dated release.
Raw LAS files alone are not inputs to these two analysis scripts. Keep the
generated predictions and their matching reports together. Model/prediction
arrays and raw data are not included in this analysis directory.

## Required input layout

`--root` is the experiment directory you generated locally:

```text
experiment-root/
  experiment_v1/dataset/dataset.json
  experiment_v1/runs/full/outer_00/predictions.parquet
  ...
  experiment_v1/runs/full/outer_09/predictions.parquet
  source/lithology scoring matrix cost function.xlsx
```

The manifest supplies `class_names` in the revision's fixed 12-class order.
The missingness analysis reads `well_id`, `label_idx`, `well_missing_rate` and
`pred_full`. S7 reads `sample_id`, `well_id`, `outer_fold`, `label_idx`,
`boundary`, `pred_full` and `pred_xgboost_argmax`. These are generated by the
revision pipeline; do not substitute independently ordered prediction arrays.

`--report-dir` contains the matching `main_report.json`, `final_report.json`
and `artifact_verification.json` produced by the revision reporting workflow.
S7 verifies the ten prediction SHA256 values, the cost-workbook SHA256 and
recomputed metrics against these records. Supply reports for your own rerun:
reports archived from another run can fail these intentional integrity checks.
The analysis targets the reported cohort of 118 wells and 1,431,383 samples.

## Recompute after generating predictions

Run from this directory, replacing the example relative paths with your own.
Quote any path containing spaces.

```sh
python recompute_missingness_strata.py --root ./experiment-root --report-dir ./final-report --out ./analysis-output/missingness
python recompute_S7_evidence.py --root ./experiment-root --report-dir ./final-report --out ./analysis-output/S7
```

For missingness, `--report-dir` is optional and adds a SHA256 check against
`final_report.json`; it does not change the statistics. S7 requires it.
Use separate output directories to retain previous analyses.

Missingness outputs retain the original filenames and schemas:

- `subgroup_current.json`: four records, including class counts, class well
  counts, well IDs, pooled Weighted F1 and its within-stratum interval.
- `subgroup_summary.csv`: `low,high,wells,rows,weighted_f1,ci95`.
- `subgroup_class_support.csv`: `missingness_low,missingness_high,class,samples,wells`
  for all 12 classes in all four strata, including observed zeros (Table S6).

The intervals use 5,000 whole-well resamples within each stratum. Each stratum
restarts `numpy.random.default_rng(20261103)` with no seed offset. Integer
multinomial well multiplicities aggregate the per-well confusion matrices;
the 2.5% and 97.5% quantiles give the original 95% intervals. Strata are
`[0,0.4)`, `[0.4,0.5)`, `[0.5,0.6)` and `[0.6,1]`; the saved upper bound
`1.000001` implements inclusion of 1.0. The intervals are conditional on the
fitted held-out predictions and are not cross-stratum significance tests.

S7 outputs retain `error_mechanism_check.json` and `error_mechanism_check.md`.
They include the full and XGBoost conditional-output metrics, the per-true-class
correct-count and Penalty decomposition, complete confusion matrices, and all
Dolomite prediction destinations. These support Table S7(a/b). The JSON schema
is unchanged; `checked_at_utc` records the current execution time. This is a
descriptive decomposition of the saved outputs, not a causal mechanism test.
